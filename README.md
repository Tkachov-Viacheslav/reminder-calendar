# 📅 Календар Нагадувань з Telegram Ботом (Vercel + Supabase + Telegram Mini App)

Сучасний інтерактивний веб-календар з підтримкою **особистих та командних календарів**, плануванням нагадувань, розумною інтеграцією з групами й темами форумів Telegram та автоматичною відправкою сповіщень.

Працює як звичайний веб-сайт у браузері, так і у вигляді **Telegram Mini App** (всередині клієнта Telegram) та як автономний **PWA** на смартфонах.

---

## 🚀 Основні можливості

### 1. Особистий та Командний Календар
- **Перемикач просторів (Workspace Switcher):** швидке перемикання між власним календарем та командними календарями робочих груп або проєктів.
- **Автоматична реєстрація групи:** при додаванні бота [@reminderveter_bot](https://t.me/reminderveter_bot) у групу або супергрупу Telegram календар автоматично створює відповідну команду.
- **Синхронізація учасників та прав:** адміністратори чату отримують статус адміністратора календаря, а для інших учасників доступні ролі *Редактор*, *Переглядач* або *Заблоковано*.

### 2. Підтримка тем форуму (Forum Topics) та маршрутизація
- **Автоматичне виявлення гілок:** бот розпізнає теми у супергрупах Telegram (`message_thread_id`).
- **Команда прив'язки `/bind <категорія>`:** написавши команду в будь-якій темі (наприклад, `/bind робота` або `/bind завдання`), ви закріплюєте сповіщення відповідної категорії за цією гілкою.
- **Гнучке налаштування у веб-інтерфейсі:** адміністратор команди може закріплювати теми за категоріями безпосередньо у модальному вікні налаштувань.

### 3. Тегування учасників та паралельні сповіщення
- **Призначення відповідальних:** можливість позначити учасників команди за нікнеймом (`@username`) або іменем зі списку.
- **Паралельні приватні сповіщення:** у момент настання нагадування бот публікує сповіщення в груповий чат/тему і водночас надсилає персональне повідомлення в приватний чат автору та призначеним учасникам із кнопкою переходу до події.

### 4. Ранковий дайджест о 09:00
- Щоранку о 09:00 (за київським часом) бот надсилає структурований бриф запланованих подій на день, об'єднуючи як особисті справи, так і завдання у підключених командах.

### 5. Інтерактивний календар та підзавдання
- **Перегляд місяця та дня:** швидкий вибір дати, кольорові маркери категорій (Головне, Робота, Навчання, Особисте, Здоров’я, Інше та власні категорії).
- **Чек-листи (підзавдання):** розбиття великих завдань на підпункти з можливістю відмічати виконання.
- **Гнучкі повторення:** одноразово, щодня, щотижня, щомісяця або **щобудня (Пн–Пт)**.
- **Мобільні свайпи:** підтримка жестів змахування вліво/вправо для виконання або відкладання на 15 хвилин.

### 6. Авторизація без паролів
- **Telegram Mini App:** безшовна миттєва ідентифікація через Telegram WebApp SDK.
- **Вхід в 1 клік:** авторизація через офіційний віджет Telegram Login.
- **Вхід за 6-значним кодом:** швидке отримання одноразового коду за командою `/code` у боті.

## 🛠 Стек технологій

- **Frontend:** React 19, Vite, Tailwind CSS v4, Lucide Icons.
- **Серверна частина та БД:** Supabase (PostgreSQL, Edge Functions Deno, Row Level Security, `pg_cron`).
- **Хостинг:** Vercel (CI/CD при пуші у гілку `main`).
- **Telegram:** Telegram Bot API, Telegram WebApp SDK, Haptic Feedback API.

## 📋 Архітектура та Edge Functions

1. **`check-reminders` (Supabase Edge Function):**
   - Викликається щохвилини через внутрішній розклад бази `pg_cron`.
   - Знаходить насталі події та надсилає їх у відповідні чати, теми чи приватні повідомлення.
   - О 09:00 генерує та надсилає ранковий дайджест.

2. **`telegram-webhook` (Supabase Edge Function):**
   - Обробляє повідомлення, команди (`/today`, `/tomorrow`, `/week`, `/code`, `/bind`, `/team`, `/help`), реєстрацію груп та інтерактивні кнопки дій.

3. **`verify-code` (Supabase Edge Function):**
   - Перевіряє та одноразово спалює 6-значні коди для входу на веб-сайті.
